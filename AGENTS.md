# HappyMeal

## Issue planning and documentation

When defining, implementing, or closing an issue, read and apply the
[issue-planning](Happymeal-BE/skills/issue-planning/SKILL.md) skill.
Store story documents in `docs/issues/<identifier>/README.md` from the repository
root. Agree on the plan with the user before implementing and preserve that plan
when completing the closing section. Write story documents in Spanish unless the
user requests another language.

Backend-specific instructions are in
[Happymeal-BE/AGENTS.md](Happymeal-BE/AGENTS.md).
