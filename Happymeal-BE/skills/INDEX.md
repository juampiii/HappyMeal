# Happymeal-BE skills

| Skill | When to use it |
| --- | --- |
| [refine-feature](../../../AITools/skills/planning/refine-feature/SKILL.md) | Refining a feature idea into a user story, or resuming one, from the business side before technical planning. |
| [plan-feature](../../../AITools/skills/planning/plan-feature/SKILL.md) | Agreeing a feature's implementation plan with the user, explaining progress, or documenting its outcome and deviations. |
| [architecture](architecture/SKILL.md) | Designing, reviewing or debugging a backend feature, validation, persistence or domain events. |
| [integration-tests](integration-tests/SKILL.md) | Writing or debugging tests for HTTP, PostgreSQL, EF Core or outbox delivery. |
| [unit-tests](unit-tests/SKILL.md) | Writing or reviewing isolated tests for domain rules, handlers or pure infrastructure logic. |

Read the selected `SKILL.md` and follow its links to the references that apply to the task. Paths in a skill are relative to its own folder.

The planning skills are maintained in the sibling `AITools` repository under
`skills/planning/`. Codex discovers them through the user's `.agents/skills` links.
Backend-specific skills remain in this repository.
