# HappyMeal frontend

Angular recipe book. UI text and feedback are in Spanish; code and documentation are in English. Use reactive forms, Router and HttpClient. Do not add UI/state dependencies without agreement. Run `npm test -- --watch=false` and `npm run build` after meaningful changes. The API is authoritative for lifecycle and validation. Preserve form input on failed actions. #35 owns authentication; #36 owns PWA installation.
